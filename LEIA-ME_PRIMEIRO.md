# Comece por aqui

1. **Testar no computador:** abra um terminal dentro desta pasta, rode `python -m http.server 8000` e abra `http://localhost:8000`.
2. **Antes de publicar:** no `README.md`, troque `SEU-USUARIO` pelo seu usuário do GitHub (aparece no link "Jogar agora").
3. **Subir pro GitHub e publicar:** siga o passo a passo que veio no chat (repositório público + GitHub Pages).
4. **Músicas:** para colocar mais músicas nas JBLs, cole o código do vídeo do YouTube (o que vem depois de `watch?v=`) no campo `videoId` de `src/data/radio.json`.

Pode apagar este arquivo depois de publicar.
